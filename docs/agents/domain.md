# Domain docs

This repository uses one Plate Editor context.

## Before changing scope or contracts

- Read `PROJECT.md` for verified lifecycle and runtime state.
- Read `CONTEXT.md` for canonical printmaking and contract language.
- Read the accepted decisions under `docs/adr/`.
- Verify both current adjacent repositories before changing a Source Contract
  or Handoff Contract.

Documents under `docs/research/` are historical inputs. If they conflict with
current evidence or an accepted ADR, surface the conflict instead of silently
promoting the old plan.
